### `> how_i_build`

```text
ground answers in evidence       → cite sources; make uncertainty visible
give agents an escape hatch      → confidence + risk + human review
separate the pipeline            → retrieval ≠ ranking ≠ generation
measure before trusting          → calibration quality matters
keep the loop bounded            → useful automation, not runaway automation
```
